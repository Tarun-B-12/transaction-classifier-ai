# Data Dictionary

## Dataset: transactions.csv

Synthetic dataset of 2,000 bank transactions, located at `data/raw/transactions.csv`. Generated by `src/generate_transactions.py` with a fixed random seed for reproducibility. This is not real customer data.

| Column | Type | Description |
|---|---|---|
| transaction_id | string | Unique identifier for each transaction, formatted as T followed by five digits (for example, T00001). |
| date | date | Transaction date, in 2023, formatted as YYYY-MM-DD. |
| description | string | Raw merchant description with realistic messiness: payment processor prefixes (TST*, SQ*, POS DEBIT), store numbers, location codes, and inconsistent casing or spacing. This is the text the classifiers interpret. |
| amount | number | Transaction amount in US dollars. |
| true_category | string | The category the synthetic data was generated from. Used only to assist building the test set. It is never given to the classifiers as input. |

## Spend Categories

The nine categories used throughout the project:

Coffee, Groceries, Gas, Restaurants, Shopping, Transport, Utilities, Entertainment, Health.

## Derived and Output Files

### data/processed/rule_based_predictions.csv

| Column | Type | Description |
|---|---|---|
| transaction_id | string | Links back to the raw dataset. |
| description | string | Original raw description. |
| clean_description | string | Normalized description: lowercased, with repeated and trailing spaces collapsed. |
| amount | number | Transaction amount. |
| true_category | string | Generator label, carried through for reference. |
| rule_based_category | string | Category predicted by the keyword classifier, or Uncategorized if no keyword matched. |

### data/processed/llm_predictions.csv

| Column | Type | Description |
|---|---|---|
| transaction_id | string | Links back to the raw dataset. |
| description | string | Original raw description. |
| amount | number | Transaction amount. |
| final_category | string | Locked ground-truth label from the hand-labeled test set. |
| llm_category | string | Category predicted by the LLM classifier. |

### eval/test_set_final.csv

The locked ground-truth test set: 150 hand-labeled transactions.

| Column | Type | Description |
|---|---|---|
| transaction_id | string | Links back to the raw dataset. |
| description | string | Original raw description. |
| final_category | string | Hand-assigned ground-truth category, after the adjudication pass. |

### eval/evaluation_results.csv

Accuracy results produced by `src/evaluate.py`.

| Column | Type | Description |
|---|---|---|
| category | string | A spend category, or OVERALL for the aggregate row. |
| n | number | Number of test transactions in that category. |
| rule_accuracy | number | Rule-based classifier accuracy for that category, as a percentage. |
| llm_accuracy | number | LLM classifier accuracy for that category, as a percentage. |
